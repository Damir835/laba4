# Задание 1

## Задача 6

### Текст задачи

В задании 1 реализовать определение класса (поля, свойства, конструкторы (не менее трех), перегрузку оператора вывода для вывода полей, заданный метод согласно варианту). Протестировать все методы, включая конструкторы, все исходные данные вводятся с клавиатуры, не забывайте проверять данные на корректность.

Вариант 6.

Название класса: `QuadraticEquation`

Поля:
- `double a`
- `double b`
- `double c`

Метод: вычисление корней квадратного уравнения. Результат должен быть массивом величин типа `double` (в нём от 0 до 2-х элементов, в зависимости от количества корней).

### Алгоритм решения

Для решения задачи создан класс `QuadraticEquation` с тремя полями типа `double`: `a`, `b`, `c` — коэффициенты квадратного уравнения `ax² + bx + c = 0`.

В классе реализованы три конструктора:

- **конструктор по умолчанию** — устанавливает коэффициенты `a = 1.0`, `b = 0.0`, `c = 0.0` (уравнение `x² = 0`);
- **конструктор с параметрами** — принимает значения `a`, `b`, `c` и проверяет их на конечность (не `NaN` и не бесконечность), при некорректном значении выбрасывает исключение `std::invalid_argument`;
- **конструктор копирования** — переписывает значения полей из другого объекта.

Для доступа к полям реализованы геттеры `GetA()`, `GetB()`, `GetC()` и сеттеры `SetA()`, `SetB()`, `SetC()`. Сеттеры также проверяют корректность переданного значения.

Метод `FindRoots()` вычисляет действительные корни уравнения и возвращает `std::vector<double>`:

1. Если `a == 0`, уравнение становится линейным `bx + c = 0`. При `b != 0` корень один: `x = -c / b`. При `b == 0` корней нет (возвращается пустой вектор).
2. Иначе вычисляется дискриминант `D = b² - 4ac`.
   - Если `D < 0` — действительных корней нет, возвращается пустой вектор.
   - Если `D == 0` — один корень `x = -b / (2a)`.
   - Если `D > 0` — два корня `x₁ = (-b - √D) / (2a)` и `x₂ = (-b + √D) / (2a)`.
3. Возвращается вектор с найденными корнями (0, 1 или 2 элемента).

Для вывода коэффициентов перегружен оператор `<<` как дружественная функция. Он выводит уравнение в виде `a x^2 + b x + c = 0` с корректными знаками (отрицательные коэффициенты выводятся со знаком `-`, положительные — с `+`).

В главной функции реализовано меню, демонстрирующее работу всех конструкторов, геттеров/сеттеров и метода вычисления корней.

# Задание 2

## Задача 6

### Текст задачи

В задании 2 добавить к реализованному в первом задании классу указанные в варианте перегруженные операции.

Вариант 6.

Название класса: `QuadraticEquation`

Унарные операции:
- `++` — увеличивает коэффициенты уравнения на 1;
- `--` — уменьшает коэффициенты уравнения на 1.

Операции приведения типа:
- `double` (неявная) — результатом является дискриминант уравнения;
- `bool` (явная) — результатом является `true`, если корни существуют, и `false` в противном случае.

Бинарные операции:
- `==` QuadraticEquation t — уравнения равны, если равны их коэффициенты;
- `!=` QuadraticEquation t — уравнения не равны, если не равны их коэффициенты.

### Алгоритм решения

В класс `QuadraticEquation` из задания 1 добавлены следующие перегруженные операции.

**Унарные операции:**

- Префиксный `++` увеличивает все три коэффициента (`a`, `b`, `c`) на 1 и возвращает ссылку на изменённый объект. Постфиксный `++` сохраняет копию исходного объекта, вызывает префиксный оператор и возвращает сохранённую копию (старое значение).
- Префиксный `--` уменьшает все три коэффициента на 1 и возвращает ссылку на объект. Постфиксный `--` аналогично возвращает копию до изменения.

**Операции приведения типа:**

- Неявное приведение к `double` возвращает дискриминант уравнения `D = b² - 4ac`. Поскольку оператор неявный, объект `QuadraticEquation` можно использовать в арифметических выражениях и при инициализации переменных типа `double`.
- Явное приведение к `bool` возвращает `true`, если уравнение имеет хотя бы один действительный корень, и `false` в противном случае. Для проверки используется метод `FindRoots()`: если вектор корней не пуст — корни существуют. Особый случай: если все коэффициенты равны нулю (уравнение `0 = 0`), возвращается `true`, так как решением является любое число. Оператор объявлен как `explicit`, поэтому преобразование выполняется только при явном указании типа (`static_cast<bool>(...)`).

**Бинарные операции:**

- Оператор `==` сравнивает объекты покоэффициентно: возвращает `true`, если `a`, `b` и `c` левого операнда равны соответствующим значениям правого операнда, иначе `false`.
- Оператор `!=` реализован через оператор `==`: возвращает отрицание результата сравнения на равенство.

В главной функции в меню добавлены пункты, демонстрирующие работу каждой операции: префиксные и постфиксные `++`/`--`, приведение к `double` (дискриминант) и к `bool` (наличие корней), сравнение двух уравнений операторами `==` и `!=`.
